# Selection Sort in C

## Description

This program sorts an array in ascending order using the Selection Sort algorithm.

Selection Sort repeatedly finds the smallest element from the unsorted portion of the array and places it at the correct position.

## Example

### Input

```text
64 25 12 22 11 90
```

### Output

```text
11 12 22 25 64 90
```
